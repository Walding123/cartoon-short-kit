# Animantra: Vector · Mulai di sini

Semua langkahnya lewat chat. Kamu tidak perlu membuka Terminal.

Bisa di **Mac** dan **Windows 10/11**.

1. **Unzip** `animantra-vector.zip` di folder Downloads. Mac: klik dua kali file-nya. Windows: klik kanan › **Extract All…** › **Extract**.
2. **Buka aplikasi Claude**, lalu pilih tab **Code**.
3. **Pilih folder** `animantra-vector` hasil unzip tadi.
4. **Ketik di chat:**
   > pasang
5. **Tunggu 5–10 menit.** Kalau Claude minta izin menjalankan perintah, klik **Izinkan** (Allow).
6. **Suara narasi.** Claude menawarkan memasang **ElevenLabs** (kalau kamu punya akun) atau **VokaStudio** (gratis, akun Google). Kamu membuat API key, lalu menempelkannya di file yang Claude bukakan di TextEdit/Notepad, **bukan di chat**. Cadangannya aplikasi **VoiceStudio**.
7. **Kalau Claude bilang selesai**, langsung lanjut di chat yang sama. Ketik misalnya:
   > buat video kita bongkar cara kerja payung otomatis

Hasilnya tersimpan di folder yang sama dengan folder yang kamu pilih di langkah 3 (**animantra-vector**), satu folder per benda.

Ada 11 jenis video (Kita Bongkar, Top List, Mitos vs Fakta, Kuis, dan lainnya). Daftar lengkap, contoh perintah, dan cara memintanya ada di **PANDUAN.md** bagian 4. Contoh videonya ada di folder **contoh-video**.

Mau membuat dan melihat video tanpa chat? Klik dua kali **Buka Studio.command** (Mac) atau **Buka Studio.bat** (Windows). Penjelasannya ada di **PANDUAN.md** bagian 4b.
