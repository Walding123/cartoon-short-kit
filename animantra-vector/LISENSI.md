# Lisensi

## Animantra: Vector (skill animantra-vector)

Skill, template adegan, mesin render, skrip audio, contoh proyek, installer dan panduan di paket ini berlisensi MIT, lihat `LICENSE` di folder utama repo. Boleh dipakai, diubah, dan dibagikan ulang, termasuk untuk konten komersial. Hak cipta (c) 2026 Walding123.

## Alat pihak ketiga

Paket ini **tidak** menyertakan alat-alat berikut. Installer mengunduhnya dari sumber resminya, dan masing-masing memakai lisensinya sendiri:

* **three.js:** MIT.
* **Playwright:** Apache-2.0. Perekam memakai Google Chrome atau Chromium.
* **FFmpeg** (dari sistem atau lewat imageio-ffmpeg): LGPL/GPL.
* **faster-whisper** dan model Whisper *small*: MIT.
* **NumPy, Pillow:** lisensi masing-masing (BSD/MIT-CMU).
* **Node.js dan Python** dari conda-forge: lisensi masing-masing.

Layanan opsional (VokaStudio, VoiceStudio) mengikuti syarat layanannya sendiri.
